隐私政策

Blink 是本地优先的软件，不收集任何数据。

零遥测

Blink 没有任何遥测、统计或回传行为。没有使用追踪，没有同意弹窗，也没有隐私开关需要配置——没有任何东西需要你选择开启或关闭。

你的项目、生成的文件和 API 密钥都留在你自己的电脑上。应用可以完全离线运行。Blink 唯一的对外网络请求，是发往你自己明确配置的模型服务商与服务(例如 Claude API，或你自己设置的部署目标)。

Blink 从不收集

  • 使用指标、令牌用量、错误率或耗时数据
  • 你的提示词、助手回复，或工具的输入与输出
  • 文件名、产物清单、项目元数据或文件内容
  • 安装标识、设备指纹，或任何形式的追踪标识

自带密钥

Blink 在每一层都是自带密钥。你为编码智能体和模型服务商配置的 API 密钥保存在本地，只用于直接与这些服务商通信。它们绝不会被发送到任何由 Blink 运营的服务——我们没有这样的服务。

关于本网站

以上说明的是 Blink 软件本身。本网站以及桌面端安装包的下载服务由服务器和对象存储承载，会产生常规访问日志(访问者 IP 地址、访问时间、请求的文件)，仅用于保障服务可用和排查故障。本网站不使用统计分析工具，不投放广告，也不设置任何用于追踪的 Cookie。
